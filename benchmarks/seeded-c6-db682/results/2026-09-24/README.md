# What This Is
This folder records the September 24, 2026 seeded-$C_6$ comparison. Both programs used NetworkX 3.3 and one worker, their runs were sequential, each program received 900 seconds on cores $0,1,3,5$, and both searches began with the same corresponding $C_6$ core. Neither program completed. The comparison measures observed search-space resolution, not total completion time or asymptotic complexity. The included files are as follows:
- report.txt: readable summary and interval results.
- intervals.csv: interval measurements for making tables.
- summary.json: full machine-readable results.
- run_plan.json: environment, hashes, order, and settings.
